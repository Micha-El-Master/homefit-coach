HomeFit Coach

Un coach de fitness à domicile : programme de 12 semaines, séances guidées, suivi, nutrition et routine Kegel. Le code source est public : github.com/Micha-El-Master/homefit-coach.

⚕️ Santé

Les programmes, les calculs nutritionnels et les conseils sont indicatifs et ne remplacent pas l'avis d'un médecin ou d'un professionnel de santé. Demande conseil avant de commencer si tu as une pathologie, une blessure, un problème cardiaque, ou si tu es enceinte. Arrête immédiatement en cas de douleur vive, de vertige ou de malaise.

🔒 Confidentialité

  • Pas de compte, pas de publicité, pas de suivi, pas de cookies.
  • Toutes tes données (profil, séances, poids saisi, réglages) restent sur cet appareil, dans le navigateur. Rien n'est envoyé à un serveur.
  • Le site est hébergé par GitHub Pages, qui peut voir, comme tout hébergeur, les requêtes de chargement de la page (adresse IP, par exemple) mais pas tes données.
  • Pour changer d'appareil, tu exportes toi-même un fichier ou un code de transfert.
  • Communauté : les boutons de partage ouvrent WhatsApp avec un message que tu peux modifier avant d'envoyer ; rien n'est envoyé automatiquement, et les messages ne contiennent que des totaux (jamais ton poids ni tes données de santé). Dans un groupe WhatsApp, ton numéro est visible des autres membres.
  • L'application lit un petit fichier public (communaute.json) pour afficher les annonces et la prochaine cohorte ; cette lecture ne transmet aucune donnée personnelle.
